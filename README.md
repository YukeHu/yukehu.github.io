# yukehu.github.io

Source for my personal academic homepage: <https://yukehu.github.io/>

Built with [Jekyll](https://jekyllrb.com/) using the [academicpages](https://github.com/academicpages/academicpages.github.io) template (a fork of [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes), © Michael Rose, MIT-licensed — see `LICENSE`).

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/>.
